  - Affects: `@typescript-eslint/typescript-estree` → `@typescript-eslint/parser`
  - Fix: Available via `npm audit fix`

- **postcss** (≤8.5.22) — XSS vulnerability and arbitrary file read via sourceMappingURL
  - Nested in: `next/node_modules/postcss`
  - Fix: Requires `next@16.4.3` (breaking change)

- **source-map-js** (1.0.0–1.2.1) — Event-loop denial of service via indexed source-map offsets
  - Fix: Available via `npm audit fix`

### Moderate Severity (4)

- **postcss-selector-parser** (<7.1.6) — Quadratic complexity in flat selector parsing (CPU exhaustion)
  - Affects: `tailwindcss`, `postcss-nested`, `@tailwindcss/typography`
  - Fix: Requires breaking changes to `@tailwindcss/typography` and `next`

### Dependency Chain Notes

- The critical Next.js vulnerabilities require a major version upgrade (13 → 16+)
- PostCSS is nested inside Next.js; cannot be patched independently without upgrading Next.js
- TypeScript ESLint dependencies have outdated transitive dependencies (minimatch, brace-expansion)
